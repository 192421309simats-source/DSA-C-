# Urban Complaint and Service Portal

A ready-to-run React + Vite + Bun website for the Urban Complaint Management and Service Request System.

## Run with Bun

```cmd
cd frontend
bun install
bun run dev
```

Then open the Local URL printed by Vite.

## Features
- Admin dashboard
- Complaint registration
- Automatic department recommendation
- Complaint search and management
- Status updates
- Complaint tracking timeline
- Department workload view
- Service performance reports
- Browser localStorage persistence
- Responsive layout for desktop/mobile

No external database is required for this demo; complaint records are stored in the browser's localStorage.
